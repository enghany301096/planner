# Smart Planner - دليل التطبيق

## مقدمة
**Smart Planner** تطبيق محلي لإدارة المشاريع والمهام وتتبع الوقت والإيرادات والمصروفات. البيانات تُحفظ على الجهاز في SQLite وليست مشفرة بـ SQLCipher.

## المميزات الفعلية

### 1. إدارة المشاريع والمهام
- إنشاء مشاريع مع وصف وصورة غلاف وتاريخ انتهاء.
- مهام بأنواع (ميزة / خطأ / تحسين) وحالات (للتنفيذ / جاري / منتهية).
- مهام فرعية، مؤقت وقت، سعر ساعة، حالة دفع وطريقة دفع.
- إنشاء مهمة بالصوت (عربي / إنجليزي).

### 2. تتبع الوقت
- تشغيل وإيقاف مؤقت لكل مهمة.
- تعديل الوقت يدوياً مع تنبيه عند الكتابة فوق الوقت المسجل.

### 3. الإدارة المالية
- إيرادات مرتبطة بالمهام المدفوعة أو تُسجل يدوياً.
- مصروفات مع فئات ورسم بياني وفلتر شهري.
- طرق دفع مع رصيد ابتدائي ورصيد محسوب (إيراد − مصروف).
- أسعار صرف USD → EGP / SAR، وتحويل الإجماليات لعملة العرض.

### 4. الحماية والتقارير
- قفل حيوي اختياري (بصمة / Face ID / رمز الجهاز). يفشل الإغلاق إذا لم يتوفر قفل.
- نسخ احتياطي واستعادة لملف قاعدة البيانات.
- تصدير فاتورة المشروع PDF.

### 5. الإعدادات
- العربية والإنجليزية، الوضع الداكن، عملة العرض، عملة المصروفات، تكلفة الساعة، خيارات الطباعة.

## التقنيات
- Flutter (Cupertino) + Provider + sqflite + easy_localization
- الإشعارات المحلية لتذكير موعد المهمة
- Firebase فقط للتهيئة وترقية التطبيق ورسائل FCM الاختيارية

## ما لا يتضمنه التطبيق
- مزامنة سحابية
- تشفير قاعدة البيانات
- أهداف ادخار أو إحصاءات ذكاء اصطناعي
