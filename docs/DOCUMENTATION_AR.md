# TaskMe - دليل التطبيق (TaskMe App Documentation)

## مقدمة
تطبيق **TaskMe** هو منصة متكاملة تجمع بين إدارة المهام الاحترافية، تتبع المشاريع، وإدارة الشؤون المالية الشخصية برؤية عصرية. تم تصميم التطبيق ليكون رفيقك التقني في تنظيم وقتك، مراقبة تقدم مشاريعك، وإدارة ميزانيتك بكفاءة عالية، مع دمج تقنيات حديثة للتتبع والتحليل.

## المميزات الرئيسية

### 1. إدارة المشاريع والمهام (التركيز الأساسي)
- **تنظيم المشاريع:** إنشاء مشاريع متعددة مع إمكانية تخصيص كل مشروع (أيقونات، ألوان، وعملات مختلفة).
- **إدارة المهام الاحترافية:**
  - تتبع حالة المهام (مستمرة، مكتملة، معلقة).
  - إرفاق الملفات والصور والمستندات لكل مهمة.
  - دعم تعدد العملات داخل المهام والمشاريع.

### 2. نظام تتبع الوقت (Time Tracking)
- **المؤقت الذكي:** إمكانية تشغيل مؤقت لحساب الوقت الفعلي المستغرق في تنفيذ المهام.
- **التعديل اليدوي:** مرونة في تعديل الوقت المسجل يدوياً مع نظام تنبيهات للتأكيد لضمان دقة البيانات.
- **تحليل الإنتاجية:** تقارير عن الوقت المستغرق في كل مهمة أو مشروع.

### 3. إحصائيات المنتجات والذكاء الاصطناعي (AI Stats)
- **لوحة بيانات ذكية:** عرض إحصائيات متقدمة للمنتجات والنماذج البرمجية.
- **تتبع الحالة:** مراقبة حالة تدريب النماذج (Total, Not Trained, Pending, Failed).
- **المنتجات التقنية:** إدارة متكاملة للمنتجات المرتبطة بالمشاريع التقنية.

### 4. الإدارة المالية والميزانية
- **تتبع الدخل والمصاريف:** تسجيل دقيق لكل العمليات المالية وتصنيفها.
- **الحصالات والمدخرات:** تحديد أهداف مالية ومتابعة التقدم نحو تحقيقها واجهة بصرية جذابة.
- **المحفظة الذكية:** إدارة الحسابات البنكية، البطاقات الائتمانية، والنقدية في مكان واحد.

### 5. الحماية والخصوصية
- **تشفير محلي:** يتم تخزين كافة البيانات على جهازك فقط باستخدام قاعدة بيانات SQLite المشفرة.
- **المصادقة الحيوية:** دعم بصمة الوجه (FaceID) أو الإصبع (TouchID) لحماية بياناتك.
- **الإشعارات:** نظام تنبيهات ذكي للتذكير بالمهام والمواعيد المالية.

## الجوانب التقنية

### التقنيات المستخدمة
- **الإطار البرمجي:** Flutter (تصميم Cupertino للهواتف الذكية).
- **إدارة الحالة:** Provider.
- **قاعدة البيانات:** SQLite (عبر `sqflite`) لضمان السرعة والأمان بدون إنترنت.
- **التدويل:** دعم كامل ومثالي للعربية والإنجليزية.
- **الرسوم البيانية:** `fl_chart` لتمثيل البيانات والإحصائيات بصرياً.

### هيكلة المشروع
- `lib/models`: نماذج البيانات للمشاريع، المهام، والعمليات المالية.
- `lib/screens`: واجهات التطبيق (المشاريع، المهام، المحفظة، الإعدادات).
- `lib/providers`: إدارة المنطق البرمجي وتدفق البيانات.
- `lib/services`: خدمات الإشعارات، قاعدة البيانات، والمصادقة.

## كيفية التشغيل والتطوير

1. تثبيت الحزم:
   ```bash
   flutter pub get
   ```
2. إنشاء ملفات الترجمة والرموز (إذا لزم الأمر):
   ```bash
   flutter pub run easy_localization:generate
   ```
3. تشغيل التطبيق:
   ```bash
   flutter run
   ```

## الخصوصية والأمان
يعتمد **TaskMe** مبدأ "الخصوصية أولاً"؛ البيانات لا تذهب إلى أي خادم سحابي ولا يتم مشاركتها، مما يمنحك السيطرة الكاملة على معلوماتك الخاصة.
